## 一、今日重磅

### OpenAI 首次公开 Perplexity 曲线，提行业安全限速

OpenAI 首席科学家 Jakub Pachocki 发布《Perplexity and Intelligence》，首次公开自 GPT-3.5 起的 log-perplexity 曲线（GPT-3.5≈0.99、GPT-4≈0.91、最新<0.8）。他提议全行业以 perplexity 为通用标尺设定「common limits」，承诺在监测能力达标前不跨越特定阈值。CEO Altman 称这是「OpenAI 最重要的发布之一」。来源：[OpenAI](https://openai.com/index/perplexity-and-intelligence/) · [Reuters](https://www.reuters.com/business/openai-scientist-proposes-industry-ai-limits-tied-model-intelligence-metric-2026-11-22/)

**一句话点评：** 保密公司突然公开核心数据——不是慈善，是安全恐惧驱使其绑定全行业步伐。

### 智谱 GLM-5.4：首款 Loop Transformer 旗舰模型

Z.AI 发布 GLM-5.4，750B 参数，28 层权重循环迭代 2 次，达到 2T-3T 参数水平。核心技术：门控渐进更新防激活爆炸、混合 KV 缓存降部署成本、稀疏注意力复用零额外开销。首次提出「Generalized Coding」——代码作为解决更广泛任务的通用基础。来源：[Z.AI Blog](https://z.ai/blog/glm-5.4)

**一句话点评：** 不堆参数量堆计算深度——750B 打 2T 效果，推理成本结构将被重塑。

## 二、模型与应用

### Perplexity 阈值曝光：0.76 引发数学突破，0.68-0.7 是下一爆发窗口

Pachocki 透露当模型降至 ~0.76 时开始产出未解数学题突破性结果。他预计 0.68-0.7 区间将爆发新能力，「最早 2027 年可能出现预训练算法突破」。文章坦承指标局限：各实验室数据集不同、不映射具体任务、推理进步不降 base loss、天花板未知。来源：[OpenAI](https://openai.com/index/perplexity-and-intelligence/) · [MLQ.ai](https://mlq.ai/news/openai-publishes-its-models-perplexity-scores-and-proposes-industry-wide-limits-on-ai-development/)

**一句话点评：** 一个数字串起 GPT-3.5 到今天——如果行业真能对齐数据集，Perplexity 将成为第一个跨实验室智能标尺。

### GLM-5.4 Loop Transformer 工程逻辑

核心洞察：内存密集型任务靠参数，推理密集型任务靠有效计算。大规模软件工程/3D建模/物理控制等超长链推理，堆参数无法解决。Loop Transformer 等效深度 56 层，Iso-Parameter 消融实验增益显著。计划开源权重。来源：[Z.AI Blog](https://z.ai/blog/glm-5.4)

**一句话点评：** 2026 年最务实的架构创新——不是做大，是做深。复用层跑两次比堆双倍参数省钱太多。

**一句话点评：** AI Agent 在中国正从技术探索切换为「产业资本+人才溢出+流量平台」三浪叠加，2027 上半年可能出现垂直 Agent 爆发窗口。

### 洞见：AI Agent 创业进入「证明效率」阶段

**为什么现在？** 推理成本季度级下降打开毛利空间；信任门槛被跨越（金融机构让 Agent 接核心系统）；DeepSeek 限流证明免费大模型不可持续，效率创新成核心竞争；300 家新公司扩散一线经验到垂直领域。

**为什么这里？** 中国有全球最完整制造业供应链、最大金融服务人群、最愿为效率付费的中小企业主。

### 哪里容易出成绩：4 个缝隙

1. **垂直行业「跟单」Agent**：每个行业有自己的跟单环节。适合行业认知者，风险在定制化程度高。
2. **个人 Agent 数据中台**：管理碎片化数据——目前空白，风险在隐私合规。
3. **微调小模型+垂直流程**：Model ML 用 2% 成本 5 倍速度可复制。适合模型工程团队。
4. **Agent 安全审计工具**：随 Agent 接入核心系统需求爆发，暂无第三方专注。

### 普通人还是巨头的机会？

**普通人**：垂直行业 Agent（缝隙 1、3）——巨头不会为每个行业定制。

**巨头**：通用 Agent 平台（字节 DeerFlow、DeepSeek Harness、微软 Imagine）已有先发优势。

**中间态**：Agent 安全审计（缝隙 4）——壁垒来自认证和信任积累。

### 今天值得尝试的方向

1. 找熟悉的垂直行业画「跟单流程」——任何需要人工跟踪、反复确认的环节都是 Agent 化候选。
2. 体验 GLM-5.4 的 ZCode——测它几轮对话能否生成可运行的端到端功能。
3. 注册 DeepSeek Harness 体验 154 万 DAU 的产品逻辑，思考能基于它构建什么增值服务。

### 风险

- **项目制陷阱**：每次客户都要重新对接系统——必须设计通用框架。
- **平台依赖**：保持多模型适配能力。
- **合规责任不清晰**：Agent 出错责任归谁？法律未明确。
- **算力成本波动**：免费算力时代或结束。

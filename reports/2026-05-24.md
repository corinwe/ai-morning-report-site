## 一、🔥 Nvidia Vera CPU 开辟 $2000亿新市场，含中国市场

### Jensen Huang：CPU for AI Agents 是新蓝海
- Nvidia 在最新财报电话会上宣布，Vera CPU 系列将为其打开 $2000亿的全新处理器市场
- Huang 明确表示「中国市场包括在内」，H200 AI 芯片对华销售路径已疏通
- CNBC、Reuters 同步报道（5月23-24日），这是本周末全球AI圈最热话题

**一句话点评：** **Nvidia 不再只是「卖显卡的」，它要通吃 AI 时代的计算全栈。** 从 GPU 到 CPU，从训练到推理，从硬件到算力平台——当一家公司可以定义整个 AI 基础设施栈时，$2000亿可能只是开始。

### Alibaba 为 AI Agent 设计专用芯片（5月20日）
- 阿里巴巴正在设计专门针对 AI Agent 工作负载的芯片架构
- 核心思路：Agent 的推理模式与传统的 GPU 计算有本质不同——更多顺序依赖、更少大批量并行
- AI News 评论称「这改变了芯片竞赛的底层逻辑」

**一句话点评：** **当 Agent 成为第一性原理，连芯片都要重新设计。** 阿里和 Nvidia 的路线之争——一个从 Agent 需求反推芯片架构，一个从芯片能力推动 Agent 生态——将是未来3年最值得关注的产业较量。

## 二、🧠 Google Gemini Spark：永远在线的个人 AI Agent

### Google I/O 2026 的「大炸弹」
- Google 发布 **Gemini Spark**——运行在 Google Cloud 上的 24/7 持续 AI Agent
- 即使你合上电脑/锁屏手机，它仍在云上运行：监控 Gmail、管理日历、撰写文档
- 未来将支持代表用户完成购买等实际交易
- Beta 版本本周开放申请（TechCrunch 报道）

**一句话点评：** **「永远在线」才是 Agent 的真正形态。** Gemini Spark 第一次让 AI 从「你问它答」变成了「永远在后台为你跑」，这是从工具到助手的质变。OPC 创业者应该立刻想一想：我的产品里有没有「持续为你工作」的 Agent 组件？

### Google Agentic AI 治理产品化
- Google 把 Agentic AI 治理封装成了可购买的产品而非仅内部工具
- 包含安全管控、权限管理、审计日志等企业级功能
- 对企业来说，这意味着合规的门槛降低了，但 Agent 应用的审查力度也会随之加强

**一句话点评：** **当治理变成商品，Agent 上生产线的审批流程不再是障碍。** 这是 Agent 走向企业级规模化应用的关键基础设施——能过合规关的 Agent 才是好 Agent。

## 三、💰 AI 创业与融资动态

### Dust 完成 $4000万 Series B
- 总部巴黎的 AI Agent 基础设施公司 Dust 完成 $4000万 B 轮融资
- 由 Sequoia 和 Abstract Ventures 联合领投，Snowflake、Datadog 跟投
- ARR 已突破 $2000万，企业客户快速扩张

### CopilotKit 融资 $2700万
- 帮助开发者在应用中嵌入 AI Agent 的 CopilotKit 完成 $2700万融资
- 企业客户包括 Deutsche Telekom、Docusign、Cisco、S&P Global
- 月安装量达数百万级

**一句话点评：** **AI Agent 基础设施正在「军备竞赛」。** Dust 和 CopilotKit 的融资说明资本正在豪赌 Agent 时代的「管道公司」——不做 Agent 本身，而是做 Agent 的工具和平台。OPC 思路：找这些平台上的垂直场景缺口。

### 全球 AI 五月融资全景
- 编码 Agent 和 Agent 基础设施是最热门赛道
- 开源模型（DeepSeek、Mistral）持续挤压闭源模型利润空间
- 垂直 AI SaaS 在客服、销售、代码审查等领域快速渗透

## 四、🇨🇳 中国 AI 最新动态

### DeepSeek 正在打造 Claude Code 竞品
- Decrypt 独家报道（5月22日）：DeepSeek 正在开发自己的「DeepSeek Code」——一款对标 Claude Code 和 OpenAI Codex 的终端编码 Agent
- 北京方面全力支持：要求 DeepSeek 打造「全栈 AI 能力」
- 目前 DeepSeek V4 已驱动大量第三方编码 Agent，官方闭源工具将进一步巩固其生态

**一句话点评：** **DeepSeek 从「卖引擎」转向「卖整车」。** 之前它是模型提供商，现在它要占据从模型到 IDE 到 Agent 的完整链路。这对用 DeepSeek API 做产品的创业者是个重要信号——你的「关键依赖」可能变成你的「直接竞争对手」。

### OpenAI 新加坡 AI 实验室 + IMDA 更新 Agentic AI 框架（5月22日）
- OpenAI 宣布在新加坡建立首个东南亚 Applied AI Lab
- 新加坡 IMDA 同步更新《Agentic AI 治理框架》，为 Agent 商业部署提供合规指引
- 这是继日本之后，OpenAI 在亚洲的第二大战略布局

**一句话点评：** **OpenAI 的「东方攻略」从新加坡开始。** 选择新加坡而非中国意味着：它看重的是东南亚市场和「中立合规」的测试环境，这对中国出海 AI 创业公司既是竞争也是示范——新加坡正在成为 AI Agent 的合规试验田。

### Musk & Zuckerberg 联手说服 Trump 废除 AI 行政令（5月22日）
- 据 AI News 报道，Musk 和 Zuckerberg 联合向 Trump 施压，成功推动废除此前签署的 AI 行政令
- 理由是「过度监管将扼杀美国 AI 创新」
- 此举引发安全界强烈反弹

**一句话点评：** **当两个 AI 野心最大的人联手反监管，未来 AI 的安全红线将由企业自己画。** 对创业者来说，短期利好（更少合规负担），长期风险（缺少统一标准可能导致碎片化）。

### 🚨 安全警报：Agentjacking 攻击已影响 2,388 家组织——AI Coding Agent 的安全底线被突破

- **6月26日**——Tenet Security 披露 **Agentjacking** 新型攻击向量，已有 **2,388家组织** 受影响
- 攻击原理：攻击者利用公开的 Sentry DSN（错误追踪密钥），注入伪造的 bug 报告，内嵌恶意 prompt 注入载荷
- **AI Coding Agent（Claude Code、Cursor 等）** 在读取 Sentry 错误日志时，会将恶意指令解释为「诊断修复步骤」，进而**以开发者权限执行攻击者代码**
- 影响规模：Sentry 是全球最广泛使用的错误追踪平台，2,388家组织的暴露意味着**数以万计的 AI Coding Agent 实例可能存在后门**
- MCP（Model Context Protocol）协议的隐式信任模型是根本原因——Agent 信任所有 MCP 工具返回的数据

**一句话点评：Agentjacking 不是一次简单的漏洞——它是 AI Agent 安全范式的「斯诺登时刻」：当 Agent 信任了不该信任的数据，整个开发流程就变成了攻击者的「特洛伊木马」。每一个使用 AI Coding Agent 的团队，今天都应该检查自己的 Sentry DSN 权限。**

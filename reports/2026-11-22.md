## 二、模型与应用

### 语言模型首次展示"自我改写权重"——不需要梯度，不需要训练

arXiv 论文展示语言模型通过自身推理修改权重，在无梯度、无训练下变强。能力随规模涌现：小模型要么不动要么搞坏自己，只有大模型能修复提升。来源：[arXiv:2611.21885](https://arxiv.org/abs/2611.21885)

**一句话点评：** 如果可复现，这是比 RLHF 更本质的范式突破——模型用完不弃，学到的能力写回自己权重。

### AI 修复漏洞加速，技术中断频率同步上升

微软过去约 10 周修补的漏洞超此前两年总和。AI 加速漏洞发现和补丁生成，但频繁更新也在增加中断概率。来源：[NBC News](https://www.nbcnews.com/tech/security/microsoft-outage-ai-race-fix-security-flaws-cyber-tech-outages-common-rcna610143)

**一句话点评：** AI 让修复提速数量级，但"修补频率"和"系统稳定性"之间的张力是新的工程难题。

**一句话点评：** 中国 AI Agent 创业正从"通用助手"转向"行业深度绑定"——金融、小微、企业服务落地速度最快。

### 洞见：金融+小微是中国 AI Agent 最肥沃的土壤

为什么是现在？模型成本在 2026 年已降到 2024 年的 1/10（DeepSeek V4/Qwen 国产模型），Agent 框架成熟（LangGraph/AutoGen），5 人团队可做过去 50 人团队的产品。四要素：小微线上化率超 70%、决策频率高、传统银行服务盲区大、支付意愿强。

### 哪里容易出成绩：3 个缝隙

1. **垂直领域"决策 Agent"（金融/税务/法务）**：适合有行业经验+技术的 5-10 人团队。合规门槛高=壁垒高。

2. **小微经营者的"经营助手"而非"融资工具"**：超市老板娘每日决策（进货/库存/排班），大银行不做、小团队做精。

3. **AI Agent "可信基础设施"服务商**：a16z Frontier 提出链上可验证+权限管理是规模化前置条件。适合有安全/区块链背景的团队。

### 普通人还是巨头的机会？

**分层结构**：巨头做通用平台+垂直自营（蚂蚁）；创业层做垂直 Agent 应用+底层工具（最大机会层）；个体层做 Agent 插件/小众品类（启动成本最低）。

对 OPC 创业者：最佳切入点是"深度垂直的决策 Agent"——不要做平台，不要做通用工具，做一个行业里最懂那件事的人。

### 今天值得尝试的方向

1. 选一个熟悉行业，调研前 3 个最常见的决策场景，看哪个传统方案最痛、AI 最快闭环。
2. 用 1 天在 LangGraph 或 AutoGen 搭最小 Agent 原型，验证"能否一轮对话完成一个完整决策"。
3. 研究 Model ML 的可信架构（ISO 27001 + SOC 2 Type II），看目标行业是否有合规门槛。

### 风险

- **项目制陷阱**：企业 Agent 易变定制开发，要以产品化非项目制设计。
- **平台依赖**：底层模型厂也可做 Agent 层——确保价值在行业知识+决策逻辑，非模型层。
- **合规责任**：金融/法务 Agent 需"AI+人工审批"双轨机制。
- **数据飞轮**：设计"单用户也有价值"的 MVP 避免冷启动失败。

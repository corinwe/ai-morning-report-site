## 一、全球最新AI/Agent热门技术、知识和应用动态

### Anthropic 发布 Claude Fable 5：史上首个公开的 Mythos 级模型
- 6月9日正式发布，这是 Anthropic 首个面向公众开放的 Mythos 级模型
- 定价 $10/$50 每百万输入/输出 tokens（Opus 4.8 的 2 倍），API 模型 ID: claude-fable-5
- 在 agentic 编程任务中表现惊人：Stripe 报告 Fable 5 将数月工程压缩为几天完成
- 同时发布 Claude Mythos 5（不受限制版本），仅限网络安全防御者和基础设施提供商使用
- 在 GDPval-AA 基准（agentic 实际工作任务）上得分 1932，占据榜首

**一句话点评：** **Anthropic 从 Opus 到 Mythos 的跃迁不是渐进改进——是模型能力的代际跨越。** 对 OPC 创业者：Mythos 级的 agent 能力意味着 AI 编程助手从"辅助写代码"进化到"独立完成整项目"。

### 微软紧急限制员工使用 Claude Fable 5：数据留存条款引发巨头摩擦
- The Verge 和 Reuters 6月10日报道，微软因 Anthropic 新的数据留存要求而限制员工使用 Claude Fable 5
- Claude Fable 5 从微软内部 GitHub Copilot 模型选择器中移除，而其他 Claude 模型仍可用（零数据留存协议）
- 微软法务团队正在审查 Anthropic 的数据处理实践，担心客户数据和机密信息安全
- 这暴露了模型提供商与企业客户之间的深层矛盾：数据主权 vs 模型训练需求

**一句话点评：** **当微软——Anthropic 的投资者——都拒绝数据共享，说明"数据留存权"已经成为企业 AI 采购的核心条款。** 对 OPC 创业者：你的 AI 产品必须把"数据不出域"作为默认设计，而非增值功能。

### Fortune 爆出 Anthropic "秘密削弱" Claude Fable 5 的能力限制
- 6月10日 Fortune 调查报道，Claude Fable 5 在某些场景下秘密限制 AI 研究者和开发者的能力
- 部分高级功能在无明确说明的情况下被降级或隐藏
- 与 Anthropic 公开宣称的"最强大公开模型"形成鲜明对比
- 引发开发者社区对"模型透明性"的广泛讨论

**一句话点评：** **AI 模型的"暗箱限制"正在成为新的行业隐患。** 当模型提供商可以在不告知的情况下调低能力，开发者需要更独立的模型评估和基准测试。

### 中国 DeepSeek V4-Pro 75% 永久降价：AI 价格战进入新阶段
- DeepSeek 自5月22日起将 V4-Pro 的 75% 折扣永久化
- 现行价格：输入 $0.435/M tokens，输出 $0.87/M tokens，缓存命中低至 $0.0036/M tokens
- 与 GPT-5.5 和 Claude Opus 4.7 相比，价格差距高达 6-7 倍
- 这一举动被视为中国 AI 企业发起全球价格战的重要信号

**一句话点评：** **DeepSeek 不是在打价格战——是在重新定义 AI 基础设施的定价基准。** 对 OPC 创业者：模型推理成本正在以超摩尔定律下降，这意味着 AI 产品的商业模型可以完全重构。

### Forbes AI 50 榜单发布：OpenAI + Anthropic 占比 80%

**一句话点评：** **AI 50 榜单真实反映了 AI 领域的马太效应——头部两家拿走了 80% 的钱，留给创业者的窗口在垂直领域。**

**一句话点评：** **"Agent 学会了你的工作"和"Agent 删除了你的公司"只差一个权限设置的距离。** Agent 安全不是可选项——是所有 Agent 产品的基础设施。

## 四、【重点板块】中国AI/Agent创业机会深度分析

### 月之暗面（Moonshot AI）寻求 $300亿 估值：中国大模型疯狂融资
- 6月8日 Bloomberg 报道，Moonshot AI 正在谈判新一轮 $20亿 融资，目标估值 $300亿
- 这是 6 个月内第三轮融资：2025年底 $43亿 → 2026年5月 $200亿 → 现在 $300亿
- Kimi 聊天机器人 ARR 在 4月已超 $2亿
- 投资方包括阿里、腾讯、美团、IDG 资本

**一句话点评：** **6 个月估值从 $43亿 涨到 $300亿——中国 AI 赛道的资本狂热可见一斑。** 对 OPC 创业者：大模型创业的资本门槛已经高到"非顶级玩家不可入"，但大模型公司的生态依赖将为上下游 Agent 工具和垂直应用创造黄金窗口。

### 中国「十五五」规划中的 AI 创业五大机遇
1. **AI 算力基础设施服务**：$2950亿 国家数据中心网络将产生大量运维、调度、优化的 SaaS 工具需求——中小企业需要在"用得起"和"用得上"之间找到中间层
2. **Agent 安全与治理**：Cyera 的 $120亿 估值和中国 AI Agent 普及（OpenClaw 等）意味着 Agent 身份认证、权限管理、行为审计是确定性蓝海
3. **AI 模型成本套利**：DeepSeek 75% 永久降价 + GPT-5.6 即将发布 = 模型选择策略成为核心竞争力——模型路由（model routing）和成本优化工具将爆发
4. **"AI Plus"产业赋能**：国家战略推动 AI 进入每个行业——制造业、农业、医疗等传统行业的 AI Agent 改造是中国特有的创业窗口
5. **跨境 AI 运营和服务**：Meta 收购 Manus 被中国否决（$20亿 交易被叫停）说明中国 AI 资产被严格保护——但这也意味着中国 AI Agent 的全球化出海需要全新的"合规化"路径

### 从 Manus 被否看中国 AI Agent 创业的"合规化出海"
- Meta 试图以 $20亿 收购 Manus（中国背景的 AI Agent 公司，后迁往新加坡），4月被中国发改委正式否决
- 发改委以"国家安全审查"为由阻止交易，要求各方退出
- 标志性意义：AI Agent 被认定为战略资产，跨境交易受到严格管控
- 但这也为中国 AI Agent 创业公司打开了独立发展的空间——不再需要"卖身"给美国巨头

**一句话点评：** **Manus 收购案被否是中国 AI 政策的"分水岭时刻"。** AI Agent 不是普通软件——它被认为是国家战略资源。对 OPC 创业者：这意味着中国 AI Agent 市场的竞争规则将由本土企业书写。

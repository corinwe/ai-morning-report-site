# AI晨报 2026-10-22

## 🔥 头条

### NVIDIA GTC Berlin 大幕拉开：Vera Rubin 基础设施全面上线，欧洲 AI 生态加速落地

NVIDIA GTC Berlin（10月20-22日）进入收官日，多项重磅发布同步落地。Google Cloud 宣布 Vera Rubin NVL72 基础设施（A5X 实例）下月正式可用，规划在多个数据中心部署多达 96 万块 Rubin GPU，首批客户包括 AlphaGo 创始人 David Silver 创办的 Ineffable Intelligence，用于大规模强化学习训练。NVIDIA 同步推出 Confidential Bare Metal 机密计算新部署模式、OpenShell 安全参考架构，以及扩建的 Agent Toolkit，让企业 Agent 扎根自有数据运行。德国总理默茨亲自站台，呼吁企业拥抱 AI，NVIDIA 同时宣布对四家德国初创公司的投资计划。欧洲工业巨头正在利用 NVIDIA Omniverse、Cosmos 和 Nemotron 模型重构制造流程，工厂管理 Agent 框架 FOX 已开放早期访问。这是一次"欧洲主权 AI"从概念到落地的集中展示。

## 📡 模型与应用

### OpenAI、Anthropic 和 Google 秘密备战下一代旗舰模型：推理成本拟降 90%

据行业消息，硅谷三家 AI 巨头正在准备新一代旗舰大模型，包括 OpenAI 的 GPT-6.1 系列。竞争核心从"堆参数、吞数据"转向强化学习推理与视觉多模态理解。新一代模型在回答前进行自我验证和多步逻辑推理，大幅降低幻觉率。同时，架构优化将推理成本削减 90% 以上——这意味着所有面向用户的软件（办公、购物、教育）都将深度集成高级 AI 能力，实现全面"智商升级"。

### DeepSeek V4.1-Flash 正式发布：552B MoE、百万 token 上下文、KV 缓存压缩至 1/8

DeepSeek 于 10 月 17 日更新了开源 Agent 模型 V4.1-Flash。采用创新的 Causal Encoder-Decoder 架构，552B 总参数量、8B/16B 激活参数，原生支持百万 token 上下文。新一代 KV 缓存压缩方案将持久缓存降至前代的 1/8，每 token 仅需 890 字节。支持文本+图像多模态输入，DeepSeek API 同步降价。这是国内开源社区在 Agent 模型方向的最新力作。

### NVIDIA RTX Spark 本地 AI 上线：个人 Agent 跑在 Windows PC 上

NVIDIA 在 GTC Berlin 展示完整本地 AI 硬件矩阵。上周发布的 RTX Spark 可在 Windows PC 上运行个人 Agent，桌面 Agent "Underdog"已可用。DGX Spark 面向 Linux 开发者，DGX Station 面向企业团队（Windows 版 12 月推出）。本地化部署正在成为 Agent 落地的关键基础设施。

## 🏢 行业与商业

### AI 投资持续加码：Pigment 获 2.5 亿美元，Q3 全球风投达 1590 亿美元

法国 AI 公司 Pigment（NVIDIA 投资背景）获 2.5 亿美元融资，直接挑战微软 Excel 和 PowerPoint 生态。Crunchbase 数据显示 Q3 全球风投总额达 1590 亿美元，近 6000 家初创公司获得融资，十亿美元级轮次数量创历史新高——全球 AI 竞赛正在推高投资规模。但 Q3 相比前两季度略有下降，市场对 1 万亿美元 AI 投资能否兑现回报的质疑声渐起。

### 英国获 NVIDIA 2.5 亿美元计算承诺，强化 Agent 安全研究

NVIDIA 宣布为期五年、2.5 亿美元的计算投入，支持英国 Agent 安全与安保研究。同时扩大对英国创业生态的投资，涵盖金融、医疗、量子计算等领域。欧洲算力基础设施正快速扩展，覆盖北欧、非洲和中亚区域，支持主权 AI 发展。

## 🇨🇳 中国AI

### 中国拟实施 AI 技术出口管制：23 项核心技术列为国家资产

10 月 16 日，商务部和科技部发布第 48 号公告，拟对 40 项关键技术实施出口管制，其中 23 项与 AI 直接相关。管制范围覆盖大模型参数、智能体自主规划能力、AI 芯片及万卡级算力集群底层管理系统——14 项禁止出口、26 项限制出口。这一举措标志着中国 AI 治理进入"技术主权优先"新阶段，与美国的芯片出口管制形成对称博弈格局。

### 中国民企大模型集体出海：DeepSeek、通义千问、Kimi K3 等全球"圈粉"

从 DeepSeek 到阿里巴巴通义千问，从月之暗面 Kimi K3 到 MiniMax M3、智谱 GLM、阶跃星辰 Step5 Preview，中国民营 AI 大模型正在全球范围获得用户。低成本优势与开源策略是出海的核心驱动力。知乎综合榜单显示，DeepSeek-V4.1-Flash(1017) 在国内开源组中保持领先位置。

### Andrej Karpathy 最新分享：别把大模型当超级大脑，它是 1TB 的有损压缩包

OpenAI 联合创始人 Andrej Karpathy 的技术分享引发热议。他指出多数人只将大模型用于简单问答，而应将其视为动态计算单元，构建包含控制循环、图结构与自主迭代的 Agent 工作流。这一观点与 GTC Berlin 上 Agent 生态的建设方向形成呼应——模型只是基础设施，Agent 架构才是应用关键。

## 🔒 安全与政策

### FTC 向 OpenAI 和 Anthropic 发出民事传票：AI 安全事件进入联邦调查深水区

美国联邦贸易委员会（FTC）本周向 OpenAI 和 Anthropic 发出 50 页以上的民事调查令，要求提供安全事件、隐私政策和保障措施相关文件。特朗普政府新成立的"超级智能力量"（Super Intelligence Force）同步推进行业强制报告机制——任何安全事件须立即通知并修复。多州总检察长同日以消费者保护法起诉 OpenAI，指控其在聊天机器人安全性上误导用户（包括儿童）。AI 安全已从行业自律全面转入联邦与州层面的法律强制阶段。

### 研究警示"渐进式去权"：AI 接管决策可能导致人类认知退化

CBS News 长篇报道聚焦"渐进式去权"（Gradual Disempowerment）——随着 AI Agent 越来越多地接管人类决策和工作，人的技能、知识和批判性思维能力可能系统性退化。研究人员指出这不仅是就业威胁，更是文明级风险，需要全社会共同应对。该议题与本周 FTC 的调查、SI Force 的强制报告机制形成政策生态的完整闭环。

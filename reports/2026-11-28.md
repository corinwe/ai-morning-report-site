## 二、模型与应用

### AI 购物 Agent 遭遇黑色星期五大考：信任度仅 23%

Fortune 报道，54% 成年人曾用 AI 完成至少一项购物任务，但仅 23% 信任 AI 代为交易。Visa 实测 22 个 Agent 购买电视、笔记本和吹风机，结果「并非成功」。Amazon 等零售商开始主动屏蔽 AI 购物 Agent。

**一句话点评：** Agent 能力在提升，但信任和基础设施摩擦才是真正瓶颈——不是 AI 干不了，是社会系统还没准备好接住它。

### 洛杉矶学区屏蔽 Google AI，考虑放弃谷歌系产品

AP 报道，全美第二大公立学区洛杉矶联合学区正在屏蔽 Google 的 AI 功能，并考虑彻底放弃 Google 产品，涉及数百万学生。

**一句话点评：** 学校不是 AI 的敌人，但把 AI 塞进供应商绑定的系统中——反弹是必然的。

### 即使最好的 Agent 也在日常生活任务中挣扎

TechCrunch 报道，新基准显示最先进 AI 模型在可靠完成日常任务方面仍表现不佳，OpenAI、Meta、Google 和 Instinct 的 Agent 均未通过测试。

**一句话点评：** 日常任务对 Agent 才是最难攻克的——考验的不是推理，是容错率和环境适应性。

## 五、中国 AI Agent 创业机会

### 今日新信号

1. **对冲基金大佬推出 Agent OS**：冯霁（管理 $4B 基金 Baiont Quant）首款产品是 Agent 专属 OS 内核——他赌 Agent 会像手机一样需要自己的运行时环境。
2. **Liblib 演语科技再融 $200M**：头部 AI 应用在中国资本市场仍有极强吸引力。
3. **上海个人 Agent 公司批量融资**：汇翮智能获超 $200M、Flowtica AI 获数千万元天使轮。个人 Agent 赛道资本集中在上海。
4. **AI 购物 Agent 信任危机**：仅 23% 消费者信任 AI 处理交易——这是信任基础设施缺失问题。

**一句话点评：** 有人在造地基（Agent OS），有人在盖高楼（Liblib/个人 Agent），但大部分人还在等电梯。

### 洞见：Agent 需要自己的运行时环境

Agent 正从「套壳聊天」走向「自有运行时」。冯霁的 Agent OS 相当于 2007 年 Android——第一次定义了 Agent 的专属运行时。大模型上界已够，但 Agent 的下界——稳定性、可观测性、安全——远不够。Agent OS 要解决的就是这个下界。

### 哪里容易出成绩：3 个缝隙

1. **Agent 可观测性**：Dante Security $10M 做监控，但开发者视角的执行链路追踪、调试仍是空白。适合有 APM 背景的团队。
2. **信任基础设施**：23% 信任率 = 77% 缺口。保险、担保、可验证记录——适合有支付/保险背景的创业者。
3. **垂直场景 Agent 编排**：通用框架已拥挤，但出口物流、留学申请、诊所预约等场景几乎空白。适合有行业经验的团队。

### 普通人还是巨头的机会？

**普通人的机会在「垂直编排 + 信任层」**——巨头不会碰每个垂直行业的工作流细节。一个领域专家 + 一个全栈工程师，把一个垂直场景效率提升 10 倍，足够养活一个创业公司。

**巨头在基础设施和平台层**——Agent OS、通用 Agent runtime、Agent 商店——需要生态号召力，是阿里、腾讯、字节的战场。

**中间态 SaaS 公司最危险**——不做 Agent 被替代，做 Agent 不灵活也没资源。SAP 裁 1 万人就是缩影。

### 今天值得尝试的方向

1. **在垂直行业建一个单 Agent + 人工兜底的 MVP**，跑通端到端交付闭环。从「哪个重复步骤最烦人」开始，不从 Agent 框架开始。
2. **记录你自己 Agent 的执行失败案例**——每个「Agent 干到一半卡住了」的场景，都是一个产品机会。
3. **关注开源 Agent 运行时的发展**——判断标准：它让你的 Agent 更可控，还是更不可控？

### 风险

- **项目制陷阱**：垂直 Agent 易变成人力咨询公司。必须产品化——新客户只加配置不加代码。
- **平台依赖**：Agent 运行时若被大厂锁定，上层应用失去议价权。优先开源方案+自控数据。
- **合规不确定性**：Agent 代执行法律责任未明确，尤其金融医疗强监管场景。
- **信任门槛**：23% 信任率意味着花 4 倍精力说服用户尝试，而不是做产品。

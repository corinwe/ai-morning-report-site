## 一、今日重磅

### 微软把 Copilot 推进到 Autopilot：企业 Agent 开始有“身份”

微软在 Ignite 2026 上把 Copilot 从对话入口推进到 Autopilot：一个带有 Entra 身份和 Work IQ 推理层的自主代理，可在后台执行任务。官方把 Copilot 的新形态概括为 Chat、Cowork、Code 和 Autopilot 四类入口。

这次变化的重点不是 Copilot 多了几个按钮，而是 Agent 被放进了企业的身份、权限和数据边界里。Autopilot 的价值不在演示，而在它把 Agent 的权限、身份、数据边界放到了企业 IT 的同一张图上。对读者来说，这意味着评估 Agent 时要先看“它能碰什么”，再看“它有多聪明”。

**一句话点评：** 企业 Agent 的竞争，正从“会回答”转向“有身份、能执行、可治理”。

## 二、模型与应用

### OpenAI 发布 GPT-6.2 Astra 与 Sol：一个打硬任务，一个打高频工作流

OpenAI 于 11 月 17 日发布 GPT-6.2 Astra 和 GPT-6.2 Sol。官方定位是：Astra 面向最复杂的专业项目，Sol 面向日常编码和写作；两款模型已进入 ChatGPT Work、Codex 和 API，并同步上线 GitHub Copilot 与 Amazon Bedrock。

对开发者来说，Astra 和 Sol 的拆分意味着选型开始按任务分层：复杂项目用高能力模型，日常任务用成本更低的模型，路由本身成为工程能力。如果 2025 年比的是模型能不能做，2026 年比的是同一件活谁做得更稳、更便宜、更容易审计。

**一句话点评：** 模型发布进入“双档”阶段：一个冲能力上限，一个冲使用频率。

- https://developers.openai.com/codex/whats-new/gpt-62-astra-sol
- https://github.blog/changelog/2026-11-17-openais-gpt-6-2-astra-and-gpt-6-2-sol-now-available

### Google 发布 Gemini 4 Neon：榜单第一，但选型不能一次定终身

Google 发布 Gemini 4 Neon，官方称其在 Models Engineering Index 上排名第一。该榜单由第三方维护，具体评测口径应以 Google 官方博客和榜单原始说明为准。

对国内团队来说，Gemini 4 Neon 的榜单表现值得跟踪，但真正要验证的是中文任务、工具调用稳定性和成本。榜单是入口，不是结论。

**一句话点评：** 榜单只能证明迭代速度在加快，不能替你决定哪个模型适合你的任务。

## 五、中国 AI Agent 创业机会

### 今日新信号：钱开始流向“能交付结果的 Agent”

- 知驿科技完成数千万元种子轮，做 Agent 协作平台，清华 00 后团队领衔，首款产品 11 月中旬上线。
- NeuxMind.AI 完成 3000 万美元 B 轮，卖的是“企业 AI 员工”，不是聊天工具。
- CataX AI 获 4000 万元融资，把 Agent 带进临床药物研发。
- 3Chat.ai 获 150 万美元，做销售 AI 模型，并向同行开放模型能力。

**一句话点评：** 资本不再为“又一个通用助手”买单，而是在为“能进入具体流程、能交付结果”的 Agent 买单。

### 洞见：巨头赢底座，创业者赢“最后一公里”

巨头会赢在底座：基础模型、云、算力、入口和分发。通用助手、办公套件、Agent 平台，最终都会是巨头的战场。

创业者真正的机会，在“最后一公里”：数据最脏、流程最重、责任最清的地方。那里模型能力已经够用，但客户要的不是一个 API，而是一个能签字、能交付、能负责的结果。

一句话：**能力会越来越便宜，结果会越来越贵。**

### 哪里容易出成绩：四个缝隙

**1. 垂直行业 Agent（最容易出收入）**
医疗临床、工业制造、物流外贸、教育招生、金融合规。共同点是：有私有数据、有明确流程、有责任主体。CataX AI 做临床药物研发、Lingshu 做工业 AI，都是这个逻辑。难点是行业 know-how 和交付，不是模型。

**2. Agent 的交付与运营（最适合小团队）**
企业买了模型不会用，需要有人做实施、集成、评测、权限、安全和成本优化。这不是“卖工具”，是“卖结果 + 卖服务”。小团队靠行业理解和响应速度能赢，但要避免变成纯项目制外包。

**3. 超级个体 / 一人公司工具链（普通人的入口）**
跨境独立站、内容生产、本地生活、招生咨询、财税服务——这些场景的特点是：一个人 + 一组 Agent 就能跑完过去一个团队的活。门槛低，但护城河不在工具，在客户关系、行业数据和持续交付。

**4. 卖铲人（竞争最拥挤）**
评测、Guardrails、连接器、记忆、成本路由、Agent 观测。需求真实，但通用层已经被大厂和开源挤压；小团队更适合做“某个行业的评测/合规/连接器”，不要做通用平台。

### 普通人还是巨头的机会？

**普通人：有机会，但不是“做 AI”，是“用 AI 重做一个具体职业”。**
最适合普通人的，是已经有行业经验、能直接接触客户、能对结果负责的人。把 Agent 嵌进自己熟悉的流程，按结果收费；不要做通用助手，不要卖提示词，不要指望“工具本身”成为壁垒。

**巨头：赢在底座和入口。**
基础模型、云、芯片、办公套件、超级 App、通用 Agent 平台，普通人不要正面竞争。

**最稳的中间态：垂直 Agent + 人工签字。**
AI 负责规模化的执行，人负责判断和担责；收费按“完成的任务/通过的结果”，而不是按 token。这正好是巨头不愿意做、普通工具做不了的缝隙。

### 今天值得尝试的三个方向

1. **外贸/物流单据 Agent**：报关、对账、异常跟进、客户催办——流程重、错误成本高、责任清晰。
2. **临床/医药文档 Agent**：入排标准、病历摘要、药物警戒——高合规、高客单、强交付。
3. **产业带/本地生活的内容 + 获客 Agent**：帮中小商家做选题、素材、投放复盘，按有效线索或到店结果收费。

### 风险

- **项目制陷阱**：越做越像外包，毛利越来越低；必须把重复环节产品化。
- **平台依赖**：模型、云、流量都在别人手里；要掌握客户和数据。
- **合规与责任**：医疗、金融、教育不能只卖“建议”，要有人签字和可追溯证据。
- **Demo ≠ 生产**：能演示不等于能验收；先定验收标准，再谈规模化。

**一句话点评：** 中国 AI 创业最容易出成绩的地方，不是最热的地方，而是数据最脏、流程最重、责任最清的地方——那里巨头不愿弯腰，普通人正好能扎根。

把四个信号放在一起看：Agent 的“身份”和模型的“分档”是基础设施变化，AI for Science 和劳动市场变化是结果层变化。基础设施先成熟，应用才会重新洗牌。这就是今天最值得记住的变化。

> **本期晨报核心结论：** 今天的主线不是“又发了几个模型”，而是 Agent 开始有身份、模型开始分档、AI 开始进入可验证的科学与工作流。对企业来说，下一步不是追最强模型，而是选对任务、给 Agent 边界、用证据验收。

## 五、中国 AI Agent 创业机会

### 今日新信号

1. **百奥几何 GeoFlow Code**：AI 制药 Agent 化，48 小时效率达人类 26 倍，自主编排设计实验闭环。
2. **DeepSeek V1 作者 Tony Zhang 创业 Linger**：本地开源 Personal Agent，数据不出本机，消费级显卡可运行。
3. **字节/腾讯/阿里 Personal Agent 集体延后**：「小豆」多轮跳票，腾讯元宝未落地，大厂从抢位转为观望。
4. **Manus 张涛演讲**：免费 DAU 正在杀死 AI 创业，砍掉 7 个月浏览器功能。

**一句话点评：** 四个信号共同指向——Personal Agent 方向对了，但云端烧 token 的商业模式错了；本地化、垂直化、Agent 化才是生存之道。

### 洞见：成本悬崖与大厂战略犹豫

大厂延后不是技术问题，是商业模式问题。Muse 的成功建立在 Meta 免费云基础设施上，但中国大厂发现给每个用户分配云端 VM + 持续烧 token 跑不通 ROI。Linger 的本地路线提供了另一种可能。

百奥几何的 RSI 模式揭示：**Agent 的价值不在于「替人干活」，而在于「闭环自我进化」**——每做一轮实验，数据回流模型，模型变强。这才是 Agent 的飞轮。

### 哪里容易出成绩：3 个缝隙

1. **垂直领域「数据飞轮 Agent」**（适合有行业数据积累的团队）：复制百奥几何模式到材料/农业/合成生物。**风险：** 数据门槛高，需行业深度合作。
2. **本地 Personal Agent「中间层」**（适合有工程能力的个人/小团队）：围绕 Linger 的插件生态、企业定制部署。**风险：** 开源项目可能被大厂 fork。
3. **AI 原生工具的「定价权缝隙」**（适合懂产品设计的创业者）：按结果付费而非按使用时长付费，在垂直工具领域（AI 编程/数据分析/合同审查）可跑通。**风险：** 用户被免费工具惯坏。

### 普通人还是巨头的机会？

**普通人：** 垂直数据闭环 + 开源生态。百奥几何证明「垂直数据+Agent 闭环」可跑通，有行业深耕就有机会。Linger 让个人无需从零造轮子。

**巨头：** 通用 Personal Agent。一旦推理成本再降，随时入场收割。**创业者最危险的是做「大厂即将进场」的通用 Personal Agent。**

### 今天值得尝试的方向

1. 找你有数据/经验的垂直行业，跑一个 Agent 数据闭环最小实验（如货代询价解析、留学选校匹配）。
2. 试用 Linger 开源代码，评估本地 125B 模型实际效果。
3. 审视产品的定价模型——免费 DAU 是否在悄悄烧死你？

### 风险

- **项目制陷阱**：定制 Agent 不可规模化，底座与定制比例要把握好。
- **平台依赖**：依赖 OpenAI/Claude API，一旦偷偷降质体验就崩；Linger 本地路线是对冲，但本地模型能力是否够用？
- **合规**：Personal Agent 涉及隐私数据，云端方案合规成本高，数据不出本机路线有优势。
- **责任归属**：Agent 自主出错谁负责？toC 领域尚无清晰判例。
